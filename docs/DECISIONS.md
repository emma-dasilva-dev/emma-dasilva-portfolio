# Decisions

- Next.js App Router
- TypeScript
- CSS Modules as the primary styling method
- English default with `/en` and `/fr`
- Next.js 16 `proxy.ts`
- Dark and light themes
- Accent: `#C6FF33`
- Space Grotesk + IBM Plex Mono
- No project screenshots
- Two case studies: STAY and Bandit Learning Journal
- Optional terminal interaction
- Normal expandable menu remains available
- Mobile-first responsive design
- Controlled technical motion only
- No gradients, glassmorphism, neon glow, fake terminal window controls, or forced CLI navigation
